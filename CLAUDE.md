# Instrucciones para Claude Code

Este repo contiene la skill `roblox-modelos-mapas` en `skills/roblox-modelos-mapas/SKILL.md`.

Si el usuario pide modelos, mapas, decoracion o sistemas de scripts en Roblox Studio (herramientas
`mcp__Roblox_Studio__*`), lee esa guia entera antes de construir y sigue sus reglas. Para instalarla de forma
permanente copia la carpeta `skills/roblox-modelos-mapas` a `~/.claude/skills/`.
