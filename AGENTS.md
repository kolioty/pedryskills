# Instrucciones para agentes (Codex y compatibles)

Este repo contiene la skill `roblox-modelos-mapas`.

Cuando el usuario pida hacer **modelos, mapas, decoracion o sistemas de scripts en Roblox Studio**
(usando las herramientas `mcp__Roblox_Studio__*`):

1. Lee entero `skills/roblox-modelos-mapas/SKILL.md` antes de construir nada.
2. Sigue sus reglas: primero `list_roblox_studios` y mirar que hay; todo en Plastic + MaterialVariant "Studs";
   modelos complejos con VoxelLib; verificar con `screen_capture` desde varios angulos antes de decir "listo";
   no borrar nada (archivar en ServerStorage); dejar waypoints de deshacer; hacer solo lo que se pide.
3. Al terminar, decir que se hizo, donde esta en el Explorer, que se interpreto y que los cambios estan en
   Studio pero no guardados.
